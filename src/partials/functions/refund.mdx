## Refund

### What this does
Returns funds to a cardholder's account, either linked to a specific original transaction or as a standalone credit.

### When to use it
Use for returning goods or services after settlement has occurred. For cancellations before settlement, use Reversal instead — it is faster and does not incur interchange fees. Partial refunds (amount less than original) are supported at the protocol level for all acquirers.

### Implementation notes

1. **Linked refund** (recommended): includes `originalTransactionId` — the gateway validates the original transaction and caps the refund at the original amount plus any tip.
2. **Unlinked refund**: omit `originalTransactionId` — sends a standalone credit. Some acquirers restrict unlinked refunds; check your acquirer agreement. Include a `transactionReference` UUID v4 on unlinked refunds so you can query status via the status endpoint.
3. Amount is in the smallest currency unit. Partial refund: set `amount` less than the original transaction amount.
4. **Card present required (per merchant configuration).** The cardholder must present their payment method at the terminal. Per merchant configuration, the **same card used in the original sale** must be presented. Physical card insert and mobile wallet (Apple Pay, Google Pay, Samsung Pay) generate **different PAN tokens** — if same-card verification is enabled and the original sale was a physical card insert, a wallet tap at refund time will produce a different token and the linked refund will be declined (and vice versa). Advise the cardholder to use the same payment method they used for the original purchase.
5. Refunds are valid up to **12 months** after the original sale date.
6. **`transactionReference` (Cloud API):** Do NOT include on linked refunds (subsequent operation). Include on unlinked refunds (original operation). HiLite paths do not support `transactionReference`.

### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `operation` | string | Yes (Cloud API) | Must be `"refund"` |
| `amount` | string | Yes | Refund amount in smallest currency unit as a string |
| `currency` | string | Yes | ISO 4217 currency code |
| `serial_number` | string | Yes (Cloud API) | Target terminal serial number |
| `terminal_type` | string | Yes (Cloud API) | Terminal model, e.g. `"PAXA920"` |
| `originalTransactionId` | string | No | Links refund to original sale (linked refund). Do NOT combine with `transactionReference` |
| `transactionReference` | string | No (Cloud API) | UUID v4. **Unlinked refunds only** — omit on linked refunds. Not supported on HiLite paths |

### Errors

| Code | Meaning | Recovery |
|---|---|---|
| `DECLINED` | Issuer declined refund | Contact acquirer support |
| `AMOUNT_EXCEEDS_ORIGINAL` | Refund amount exceeds original sale | Reduce amount |
| `ORIGINAL_NOT_FOUND` | Provided reference not found | Verify reference; try unlinked refund |
| `TIMEOUT` | Terminal did not respond | Check connection; retry |
