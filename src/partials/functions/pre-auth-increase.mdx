### Pre-Authorization Increase / Decrease

Adjusts the held amount on an open pre-authorization before capture.

**When to use:** When the expected final charge has changed after the initial hold was placed — for example, a hotel stay is extended (increase) or a car rental is returned early (decrease). Send before capture.

**Implementation notes:**
1. `increaseAmount` is the **delta** — the amount to add to (or subtract from) the current hold, not the new total. To raise a $100 hold to $120, send `"increaseAmount": "20.00"`. To lower it to $80, send `"increaseAmount": "20.00"` with `"subtract": "1"`.
2. Increase above the original amount is subject to acquirer and issuer limits. Check the acquirer capabilities matrix.
3. The `originalTransactionID` must be the `transactionID` from the pre-auth create result.

<Tabs groupId="integration-path">
<TabItem value="cloud-api" label="Cloud API">

**Increase** — add to the current hold:
```http
POST https://cloud.handpoint.com/preauthorization/increase
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "originalGuid": "01236fc0-8192-11eb-9aca-ad4b0e95f241",
  "increaseAmount": "20.00"
}
```

**Decrease** — subtract from the current hold by adding `subtract: "1"`:
```http
POST https://cloud.handpoint.com/preauthorization/increase
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "originalGuid": "01236fc0-8192-11eb-9aca-ad4b0e95f241",
  "increaseAmount": "20.00",
  "subtract": "1"
}
```

Both operations use the same endpoint. `increaseAmount` is the delta in major units (decimal string). `originalGuid` is the `transactionID` from the pre-auth create result.

**Cloud API** — `POST /preauthorization/increase`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `originalGuid` | string | Yes | `transactionID` from the pre-auth create result |
| `increaseAmount` | string | Yes | Delta amount in major units as a decimal string, e.g. `"20.00"` |
| `subtract` | string | No | Pass `"1"` to subtract the delta (decrease the hold) instead of adding it |
| `tipAmount` | string | No | Tip amount to add, in major units as a decimal string, e.g. `"2.00"` |
| `customerReference` | string | No | Integrator-defined reference forwarded as-is to the gateway |

**Android SDK** — `preAuthorizationIncrease(amount, currency, originalTransactionID)`:

| Parameter | Type | Description |
|---|---|---|
| `amount` | `BigInteger` | Delta amount in minor currency units |
| `currency` | `Currency` | Currency of the original pre-authorization |
| `originalTransactionID` | `String` | `transactionID` from the pre-auth create result |

### Errors

**Cloud API (`POST /preauthorization/increase`)** — synchronous:

| HTTP | `code` | `message` | Meaning | What to do |
|---|---|---|---|---|
| `400` | `5001` | `NullPointerException` | `originalGuid` not found | Verify the GUID is the `transactionID` from the pre-auth create result. Code `5001` for this endpoint always means the original transaction was not found |
| `403` | — | `No valid key found in header` | Invalid API key | Check `ApiKeyCLoud` header |
| `422` | `VALIDATION_FAILED` | Missing or wrong field name | The required field is `increaseAmount`, not `amount` | See `details` array in response for the specific missing property |

:::note
`increaseAmount` is required for both increase and decrease operations. Sending `amount` results in a `422 VALIDATION_FAILED` error. To decrease, send `increaseAmount` with `subtract: "1"`.
:::
