### MOTO Pre-Authorization

Places a MOTO (Mail Order / Telephone Order) pre-authorization hold by commanding a PAX terminal to display a manual card entry screen. Reserves funds without charging — the ISV captures, increases, or voids before settlement.

**When to use:** For hotel or car rental reservations taken over the phone where the cardholder cannot be present. The operator keys the card number on the PAX terminal's manual entry screen.

**Implementation notes:**
1. The MOTO pre-auth flow supports the full pre-auth lifecycle: Increase / Decrease → Capture → Void.
2. PAX terminal required — HiLite has no keyed-entry screen and does not support MOTO pre-auth on either path.

<TabItem value="cloud-api" label="Cloud API">

Commands a PAX terminal to display a manual card entry screen. The operator types the card number, expiry, and CVV. Amount in **smallest currency unit**. Result is async — poll `GET /transaction-result/{transactionResultId}`.

```http
POST https://cloud.handpoint.com/transactions
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "operation": "moToPreAuthorization",
  "amount": "10000",
  "currency": "USD",
  "terminal_type": "PAXA920",
  "serial_number": "082104578",
  "transactionReference": "3cfe2fd3-34c2-5d78-a4e0-2e5b668f5e5f"
}
```

Store `transactionResultId` from the 202 response, poll `GET /transaction-result/{transactionResultId}` until `finStatus` is set, then store `transactionID` from the result for capture / increase / reversal.

**Cloud API** — `POST /transactions`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `operation` | string | Yes | Must be `"moToPreAuthorization"` |
| `amount` | string | Yes | Amount in **smallest currency unit** — `"10000"` = $100.00 |
| `currency` | string | Yes | ISO 4217 currency code |
| `terminal_type` | string | Yes | Terminal model, e.g. `"PAXA920"` |
| `serial_number` | string | Yes | PAX terminal serial number |
| `transactionReference` | string | Recommended | UUID v4 for idempotency |

**Android SDK** — `motoPreauthorization(amount, currency)`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `amount` | `BigInteger` | Yes | Pre-auth hold amount in minor currency units |
| `currency` | `Currency` | Yes | ISO 4217 currency |
