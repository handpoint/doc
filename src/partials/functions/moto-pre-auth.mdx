### MOTO Pre-Authorization

Places a pre-authorization hold via MOTO (Mail Order / Telephone Order), using a stored card token. No terminal entry or card presentation is required.

**When to use:** For hotel or car rental reservations taken over the phone where the cardholder cannot be present. A card token must already exist from a prior tokenization.

**Implementation notes:**
1. Requires a card token — pass via `MoToOptions.cardToken`. Raw PAN is never accepted.
2. The MOTO pre-auth flow supports the full pre-auth lifecycle: Increase / Decrease → Capture → Void.
3. PAX-only — HiLite has no card entry screen and does not support MOTO pre-auth.

    }

**Android SDK** — `motoPreauthorization(amount, currency, options)`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `amount` | `BigInteger` | Yes | Pre-auth hold amount in minor currency units |
| `currency` | `Currency` | Yes | ISO 4217 currency |
| `options` | `MoToOptions` | No | Pass `cardToken` for back-office MOTO pre-auth |
