## Tokenized Operation (charge stored card)

### What this does
Processes a sale using a stored card token, without requiring the cardholder to present their card. The token represents a card that was previously tokenized in a card-present or online transaction.

### When to use it
Use for recurring charges, subscription billing, or any scenario where the cardholder has previously consented to card-on-file and a token exists. This is separate from MOTO — a tokenized operation does not require the `motoChannel` flag and is not classified as card-not-present by default.

:::info Token provider required
Handpoint does not issue card tokens directly. Tokens must come from a supported token provider (e.g. TSYS, Paysafe, Tokenex) whose de-tokenization service is integrated with your acquirer.
:::

### Implementation notes

1. A card token must exist from a prior [Tokenization](/functions/tokenization) operation.
2. The token must be from a provider supported by your acquirer.
3. No terminal or card is required — the operation is submitted server-side.
4. For on-terminal MOTO (operator types card details at the terminal), see [MOTO](/functions/moto).

### Code

<Tabs groupId="integration-path">
<TabItem value="cloud-api" label="Cloud API">

```http
POST https://cloud.handpoint.com/transaction
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "action": "SALE",
  "amount": 1000,
  "currency": "USD",
  "cardToken": "TOKEN_FROM_PREVIOUS_TOKENIZATION",
  "transactionReference": "2bfde1fc-23b1-4c67-93d9-1d4a557f4d4f"

```

No `motoChannel` flag — this is a tokenized card-on-file sale, not a MOTO transaction.

<TabItem value="android-pax" label="Android (PAX)">

Use `MoToOptions.cardToken` to pass the stored token via the Android SDK:

```kotlin
val options = MoToOptions()
options.cardToken = "TOKEN_FROM_PREVIOUS_TOKENIZATION"

hapi.motoSale(BigInteger("1000"), Currency.USD, options)

override fun endOfTransaction(result: TransactionResult, device: Device) {
    if (result.finStatus == FinancialStatus.AUTHORISED) {
        // charge accepted
    }
}
```

### Parameters

**Cloud API** — `POST /transaction`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `action` | string | Yes | Must be `"SALE"` |
| `amount` | number | Yes | Amount in smallest currency unit |
| `currency` | string | Yes | ISO 4217 currency code |
| `cardToken` | string | Yes | Token from a supported token provider |
| `transactionReference` | string | Recommended | UUID v4 for idempotency and result polling |
