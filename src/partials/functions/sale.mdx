## Sale

### What this does
Authorises and captures a card-present payment in a single step.

### When to use it
Use for standard retail and hospitality transactions where the cardholder is present and the amount is known before the transaction starts. Do NOT use when the final amount may change after authorisation — use Pre-Authorization instead.

### Implementation notes

1. The terminal handles EMV chip, contactless, and magnetic stripe automatically — you do not specify the card entry method.
2. The SDK returns an `OperationStartResult` synchronously with a `transactionReference`. The actual result arrives asynchronously via the events listener/callback.
3. Always store the `transactionReference` immediately — you need it for any subsequent reversal.
4. Amount is in the smallest currency unit (cents/pence). `1000` = $10.00 USD.
5. **`transactionReference` (Cloud API):** Send a unique UUID v4 on **original transactions only** (Sale, MOTO Sale, Pre-Authorization, unlinked Refund). Do not send a new `transactionReference` on subsequent operations (Reversal, linked Refund, Pre-Auth Capture, Void). The gateway uses this value to group all linked operations — query `GET /transactions/{transactionReference}/status/all` on `transactions.handpoint.com` to retrieve the full operation chain. HiLite integration paths do not support `transactionReference`.

### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `operation` | string | Yes (Cloud API) | Must be `"sale"` |
| `amount` | string | Yes | Amount in smallest currency unit as a string. `"1000"` = $10.00 |
| `currency` | string | Yes | ISO 4217 currency code. e.g. `"USD"`, `"GBP"`, `"EUR"` |
| `serial_number` | string | Yes (Cloud API) | Target terminal serial number |
| `terminal_type` | string | Yes (Cloud API) | Terminal model, e.g. `"PAXA920"` |
| `transactionReference` | string | No (Cloud API) | UUID v4. Required for status queries. Send on **original transactions only** (Sale, MOTO Sale, Pre-Auth, unlinked Refund) — not on subsequent operations. Not supported on HiLite paths |
| `customerReference` | string | No (Cloud API) | Optional merchant reference forwarded to the acquirer |

**Android SDK — `Options` fields** (pass as optional third argument to `hapi.sale()`):

| Field | Type | Description |
|---|---|---|
| `customerReference` | `String?` | Merchant reference echoed in `TransactionResult.customerReference` and forwarded to the acquirer |
| `tipConfiguration` | `TipConfiguration?` | Pre-configure tip prompt shown on the terminal (percentages, amounts, or skip tip) |
| `budgetNumber` | `String?` | Instalment / budget number (South African acquirers only) |
| `pinBypass` | `Boolean` | `true` to offer a PIN bypass option to the cardholder (where acquirer-supported) |
| `signatureBypass` | `Boolean` | `true` to skip signature capture (where acquirer-supported) |
| `checkDuplicates` | `Boolean` | `true` to enable duplicate transaction detection on the gateway |
| `merchantAuth` | `MerchantAuth?` | Override merchant ID / terminal ID for multi-MID support |
| `metadata` | `Metadata?` | Custom key-value pairs echoed in the result and stored in the transaction feed |
| `moneyRemittanceOptions` | `MoneyRemittanceOptions?` | Money remittance fields for regulated money transfer transactions |

### Errors

| Code | Meaning | Recovery |
|---|---|---|
| `DECLINED` | Issuer declined the card | Ask cardholder to try another card |
| `TIMEOUT` | Terminal did not respond within timeout | Check terminal connection; retry |
| `CANCELLED` | Cardholder cancelled at terminal | No action required |
| `COMMUNICATION_ERROR` | Network failure | Verify connectivity; retry |
