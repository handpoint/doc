### Void Pre-Authorization

Releases a pre-authorization hold without capturing funds.

**When to use:** When a booking is cancelled or the pre-auth is no longer needed. Always void unused pre-auths — unreleased holds affect cardholder available credit.

```http
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

  "action": "VOIDPREAUTHORISATION",
  "original_transaction_reference": "pre-auth-abc-123"
}
```
