## Batch Operations {#batching}

Three Backoffice REST API endpoints for batch management — calls go directly to the payment gateway, no terminal or SDK involved.

#### When to use it
Use when you need to settle at a specific time rather than waiting for automatic batch close. Most US host-capture merchants use automatic batch close (~11pm EST) — manual close is only needed for specific settlement timing requirements.

#### Implementation notes

1. **US host-capture acquirers only.** EU acquirers use automatic settlement and do not require manual batch close.
2. After batch close, tip adjustments and reversals are no longer possible — only post-settlement refunds.
3. Auto-close is the default for US host-capture merchants at approximately 11pm EST. Manual close is an alternative, not an addition.

### Batch Close {#batch-close}

Closes the current open batch and triggers settlement with the acquirer. Omit `batchNumber` to close the currently open batch.

<Tabs groupId="integration-path">
<TabItem value="backoffice" label="Backoffice">

```http
POST https://cloud.handpoint.com/batch/close
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "serialNumber": "082104578",
  "deviceType": "PAXA920"
}
```

</TabItem>
</Tabs>

### Batch Summary {#batch-summary}

### Batch Detail {#batch-detail}

Retrieves individual transactions in a batch for reconciliation. Results are **paginated** — TSYS returns a maximum of 5 transactions per call, in descending order (newest first).

**Pagination:** On the first call, omit `retrievalReferenceNumber`. Each response item includes a `retrievalReferenceNumber`. Pass the `retrievalReferenceNumber` of the **last (oldest) item** in the current page to get the next page. Stop when the `details` array is empty.

<Tabs groupId="integration-path">
<TabItem value="backoffice" label="Backoffice">

First page (no cursor):

```http
POST https://cloud.handpoint.com/batch/detail
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "serialNumber": "082104578",
  "deviceType": "PAXA920",
  "batchNumber": "001"
}
```

Next page (pass the oldest RRN from the previous response):

```http
POST https://cloud.handpoint.com/batch/detail
ApiKeyCloud: YOUR_MERCHANT_API_KEY
Content-Type: application/json

{
  "serialNumber": "082104578",
  "deviceType": "PAXA920",
  "batchNumber": "001",
  "retrievalReferenceNumber": "627121800441"
}
```

</TabItem>
</Tabs>

#### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `serialNumber` | string | Yes | Terminal serial number |
| `deviceType` | string | Yes | Terminal model, e.g. `"PAXA920"` |
| `batchNumber` | string | No (Batch Close) / Yes (Summary, Detail) | Batch number to close or query. Omit on Batch Close to target the currently open batch |
| `retrievalReferenceNumber` | string | No | Pagination cursor for Batch Detail. Pass the `retrievalReferenceNumber` of the oldest item in the previous page to retrieve the next page. Omit to get the most recent page |

#### Errors

| Code | Meaning | Recovery |
|---|---|---|
| `BATCH_ALREADY_CLOSED` | Batch was already closed (auto-close ran) | No action needed |
| `NO_TRANSACTIONS` | No transactions in current batch | No action needed |
