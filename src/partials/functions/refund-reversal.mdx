### Refund Reversal

Cancels a refund before settlement. Used when a refund was issued in error and needs to be voided before it reaches the cardholder.

**When to use:** When a refund was sent in error within the same business day (before batch close). After settlement, the refund cannot be reversed — contact your acquirer.

**Implementation notes:**
1. `amount` and `currency` must match the original refund exactly.
2. The `originalTransactionID` is the `transactionID` from the refund result — not the original sale.
3. Android HiLite does not support refund reversal. iOS HiLite and Cloud API (via connected PAX terminal) do.
4. Not available on all acquirers — check the acquirer capabilities matrix.

**Cloud API** — `POST /transactions`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `operation` | string | Yes | Must be `"refundReversal"` |
| `amount` | string | Yes | Amount in minor currency units — must match original refund exactly |
| `currency` | string | Yes | ISO 4217 currency code — must match the original refund |
| `terminal_type` | string | Yes | Terminal model, e.g. `"PAXA920"` |
| `serial_number` | string | Yes | Terminal serial number |
| `originalTransactionId` | string | Yes | `transactionID` from the refund result |

**Android SDK** — `refundReversal(amount, currency, originalTransactionID)`:

| Parameter | Type | Required | Description |
|---|---|---|---|
| `amount` | `BigInteger` | Yes | Amount of the refund to reverse — must match original refund |
| `currency` | `Currency` | Yes | Currency of the original refund |
| `originalTransactionID` | `String` | Yes | `transactionID` from the refund result |

**iOS HiLite** — `refundVoidWithAmount:currency:transaction:`:

| Parameter | Type | Description |
|---|---|---|
| `amount` | `NSInteger` | Amount in minor currency units — must match original refund |
| `currency` | `NSString *` | ISO 4217 currency code string |
| `transaction` | `NSString *` | `eFTTransactionID` from the refund result |

**Cordova** — `handpoint.refundReversal(config, success, error)` — Android only:

| Field | Type | Description |
|---|---|---|
| `amount` | number | Amount in minor currency units |
| `currency` | number | `handpoint.Currency.USD` (or other currency enum) |
| `originalTransactionID` | string | `transactionID` from the refund result |
