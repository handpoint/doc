### MOTO Reversal

Reverses a MOTO sale before settlement. No card or terminal is required — the reversal is submitted electronically using the original MOTO transaction ID.

**When to use:** When a MOTO sale needs to be cancelled before the batch closes. Use instead of MOTO Refund for same-day cancellations — faster and no interchange fee. After settlement, use MOTO Refund instead.
