## Money Remittance

### What this does
Processes a payment transaction flagged as a money transfer — subject to specific network rules for remittance transactions.

### When to use it
Use when processing money transfer payments (e.g. sending money to family abroad) where the merchant category requires the remittance flag. Do NOT use for standard retail — use Sale instead.

### Implementation notes

1. Money remittance transactions are flagged with a specific MCC and network indicator.
2. Not all card brands support remittance in all geographies — verify with your acquirer.
3. The API call is similar to a Sale but with an additional remittance flag.

### Parameters

| Name | Type | Required | Description |
|---|---|---|---|
| `amount` | integer | Yes | Transfer amount in smallest currency unit |
| `currency` | string | Yes | ISO 4217 currency code |
| `moneyRemittance` | boolean | Yes | Must be `true` |
| `terminal_serial_number` | string | Yes (REST) | Target terminal |

### Testing
Test money remittance transactions on the TEST/DEMO merchant or staging device the same way as standard sales.
