# Build with AI agents

Handpoint provides machine-readable resources so AI coding agents (Claude Code, Codex, Cursor, and others) can generate accurate payment integrations without hallucinating API fields, acquirer constraints, or unsupported capability combinations.

## Quick start for agents

```
1. Fetch https://developer.handpoint.com/llms.txt for the full machine-readable reference:
   acquirer × feature support matrix, per-path code examples, and all reference page URLs.

2. Load the handpoint skill before writing any integration code:
   https://developer.handpoint.com/.well-known/skills/handpoint.md

3. Load a task-specific skill for the operation you are implementing.
```

## Machine-readable reference — llms.txt

[`/llms.txt`](/llms.txt) contains:
- The complete acquirer × feature support matrix (which acquirer supports which capability on which integration path)
- Per-path code guidance (Cloud API, Android PAX, Android HiLite, iOS, Cordova, Back Office)
- All reference page URLs

Fetch it at the start of any Handpoint integration task.

## Integration paths — quick reference

| What you're building | Path | Hardware |
|---|---|---|
| Server controls PAX terminal via HTTP (any language) | [Cloud API (REST)](/back-office/rest-api-no-reader) | PAX SmartPOS |
| Android app running on the PAX terminal itself | [Android SDK (PAX)](/reference/android-sdk-setup) | PAX SmartPOS |
| Android or iOS app paired with a portable card reader | [Android / iOS SDK (HiLite)](/reference/android-sdk-setup) | HiLite Bluetooth |
| Server-side operations without a terminal | [Back Office REST API](/back-office/rest-api-no-reader) | None |
| EU online checkout | [SmartBoard](/acquirers/smartboard) | None |

## Common agent mistakes to avoid

- **Do not assume all acquirers support the same features.** EPI requires daily batch close; PAYSAFE does not support remote sale or pre-authorization; EmerchantPay/Paystrax include tipAmount in the sale, not post-sale. Always load `acquirer-selection` first.
- **Do not retry UNDEFINED transactions.** `finStatus: UNDEFINED` means the result is unknown — retrying may double-charge. Use the Transaction Feed API to recover.
- **The header is `ApiKeyCloud`**, not `Authorization` or `Api-Key`.
- **Amounts are in minor currency units.** `1000` = $10.00, not $1000.
- **Reversals are synchronous; sales and refunds are asynchronous.** Poll for sales and refunds; reversal response is immediate.
